# Physics-informed-learning-captures-nonmonotonic-pore-scale-biofilm-growth
This code is from the paper 'Physics-Informed Learning Captures Nonmonotonic Pore-Scale Biofilm Growth,' with Qiang Ye as the first author.

Based on microfluidic experimental data, our paper uses Physics-Informed Neural Networks (PINN) to perform high-fidelity simulations of the biofilm growth process. It also compares the simulation performance of PINN with purely data-driven approaches and uses PINN to invert the self-limiting parameters in the modified biofilm diffusion model. Additionally, transfer learning was used to validate the generalization capability of PINN in similar new scenarios. The main code and dataset from the paper are available in this repository.
