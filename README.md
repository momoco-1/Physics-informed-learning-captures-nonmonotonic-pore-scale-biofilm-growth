# Physics-informed-learning-captures-nonmonotonic-pore-scale-biofilm-growth
This code is from the paper 'Physics-Informed Learning Captures Nonmonotonic Pore-Scale Biofilm Growth,' with Qiang Ye as the first author. The paper uses Physics-Informed Neural Networks (PINN) to perform high-fidelity simulations of the biofilm growth process. The main code and dataset from the paper are available in this repository.
